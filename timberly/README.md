# Timberly frontend

React storefront powered by Vite.

```bash
npm ci
npm run dev
npm run build
```

Set `VITE_API_BASE_URL` to the Django API root (e.g. `http://127.0.0.1:8000/api`) when deploying to another host.

See the [root README](../README.md) for the full-stack installation, API, and deployment instructions.
